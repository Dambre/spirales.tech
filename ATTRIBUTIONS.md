# Attributions

## Fonts

The site self-hosts its typefaces from `public/fonts/`, so this repository
redistributes them. All three are licensed under the
[SIL Open Font License 1.1](public/fonts/OFL.txt), a copy of which ships
alongside the font files.

| Family                                                          | Copyright                                                                                            |
| --------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| [Unbounded](https://github.com/googlefonts/unbounded)           | Copyright 2022 The Unbounded Project Authors                                                          |
| [DM Sans](https://github.com/googlefonts/dm-fonts)              | Copyright 2014 The DM Sans Project Authors                                                            |
| [DM Mono](https://github.com/googlefonts/dm-mono)               | Copyright 2020 The DM Mono Project Authors                                                            |

The woff2 subsets are fetched from the Google Fonts CDN by
`scripts/fetch-fonts.mjs` and are unmodified.

## History

This project started as a Figma Make export, which shipped a full
[shadcn/ui](https://ui.shadcn.com/) component library under the
[MIT license](https://github.com/shadcn-ui/ui/blob/main/LICENSE.md) and a set of
[Unsplash](https://unsplash.com) reference images. Neither is used by the site
and both were removed.
